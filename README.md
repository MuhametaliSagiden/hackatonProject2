# Certificate Radar

Централизованное обнаружение, инвентаризация и контроль цифровых сертификатов корпоративной инфраструктуры.
Разработано для Хакатона «Автоматизация и повышение надёжности корпоративной инфраструктуры».

> **Ключевой принцип:** *«Обнаружить проблему до того, как она станет инцидентом»*.

## Быстрый старт

```text
uv sync
uv run radar init-db
uv run radar import targets.csv
uv run radar scan
uv run radar serve
```

Цели могут быть DNS-именами, IP-адресами, `host:port`, HTTPS URL или CIDR.

## Настройки

Основные параметры находятся в `config.yaml` или `config.example.yaml`:
таймаут и число потоков сканирования, DNS overrides, дополнительные CA-файлы,
пороги статусов, каналы уведомлений и расписание. Секреты SMTP и Telegram
задаются в `.env`; файл `.env` не следует коммитить.

## Добавление новой проверки

Создайте модуль в `radar/checks/` с методом `run(ctx) -> list[Finding]`,
используйте `CheckContext`, а затем зарегистрируйте экземпляр проверки в
`radar/checks/__init__.py` в списке `ALL_CHECKS`. Тексты причин и рекомендаций
добавляются в `radar/recommendations_ru.yaml`.

## Лабораторный стенд

```text
uv run python lab/make_certs.py
uv run python lab/serve.py
uv run python scripts/demo_reset.py --seed
uv run radar serve
```

Откройте `http://127.0.0.1:8000`. Лаборатория использует только локальные TLS-подключения и SNI; HTTP-запросы к целям не выполняются.

## Windows Server / IIS

Для стенда используйте Windows Server 2025 Datacenter x64 Gen2 с полноценным
GUI. Скрипт `lab/windows/setup-iis-lab.ps1` запускается от имени администратора
на Windows Server 2019+ и создаёт IIS-сайты с HTTPS/SNI на порту 443.
Подробная последовательность и требования к сети описаны в
`lab/windows/README.md`.

## Архитектура и безопасность

`radar/scanner` выполняет DNS и TLS, `analysis.py` формирует находки, `risk.py` считает риск, `notify` отправляет уведомления, `export` формирует отчёты, а `web` предоставляет UI/API. Секреты задаются через переменные окружения. Продукт работает в read-only режиме относительно целевых сервисов.

## Ограничения MVP

SQLite рассчитан на один экземпляр приложения. Проверка цепочки использует
системное хранилище, certifi и дополнительные CA-файлы. Сканер не выполняет
HTTP-запросы и не определяет сертификаты сервисов без TLS. Расписание
обновляется сразу после сохранения настроек.
