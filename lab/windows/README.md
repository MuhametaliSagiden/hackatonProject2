# Windows Server / IIS lab

На Windows Server 2019+ установите IIS и импортируйте сертификаты из `lab/certs`. На машине сканера задайте `dns_overrides` для лабораторного домена и укажите `extra_ca_files` на root CA. Повторно создавайте сертификаты перед демонстрацией, поскольку сроки считаются от момента генерации.
