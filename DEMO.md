# Демонстрационный сценарий для жюри (7 минут)

> **Ключевой посыл:** *«Просроченный сертификат становится инцидентом. Certificate Radar обнаруживает технический риск до того, как пострадают пользователи и бизнес»*.

---

## Подготовка перед выходом к жюри (Pre-Flight Checklist)
1. Открыть терминал в папке проекта: `cd c:\Radar\hackatonProject2-push`
2. Запустить лабораторный стенд TLS (в отдельном окне):
   ```powershell
   uv run python lab/serve.py
   ```
3. В основном окне сбросить стенд и убедиться в готовности:
   ```powershell
   uv run python scripts/demo_reset.py --seed
   uv run radar serve
   ```
4. Открыть в браузере: `http://127.0.0.1:8000`

## Запасной план (Fail-Safe Mode)

Если на защите произошёл непредвиденный сбой оборудования или сети:
1. **Сетевые проблемы / недоступен хост**: Всегда работает локальная лаборатория `lab/serve.py` на `127.0.0.1:8443` с встроенным корневым CA.
2. **Сканирование не может выполниться**: Мгновенно восстановить готовую базу данных:
   ```powershell
   Copy-Item data/radar_demo_seed.db data/radar.db -Force
   ```
3. **Нет веб-сервера / браузера**: Показать готовые демонстрационные выгрузки в папке `demo/` (`certificates.xlsx`, `certificates.html`, `certificates.csv`) и терминальный CLI:
   ```powershell
   uv run radar scan
   ```
4. **Нет подключения к интернет**: Каналы оповещения Console работают локально, SMTP направляется в локальный заглушечный сервис или системный журнал.
